# Data Directory

## Directory rules

- `raw/` contains unchanged downloaded source files.
- `interim/` contains temporary validated or reshaped data.
- `processed/` contains model-ready data generated by scripts.

Raw, interim, and processed data are excluded from Git by default. The repository should contain instructions and validation code, not the full M5 dataset.

## M5 data requirements

The initial pipeline expects the M5 sales, calendar, product, store, and price files. Exact filenames depend on the download package and must be recorded after download.

The data checks must validate item-store-date keys, dates, sales values, joins, missing values, long runs of zeros, and possible future leakage.

## Important limitation

Observed sales are not automatically unconstrained demand. A zero sale may mean no demand, unavailability, a product lifecycle event, or a data issue. Do not create an availability label without evidence.
